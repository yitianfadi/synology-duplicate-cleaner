# 重复文件清理与影音工具 · Duplicate Cleaner & Media Toolkit（群晖 DSM 7 SPK）

一款为 Synology DSM 7.x 编写的重复文件清理与影音工具：提供**哈希精准匹配**、**图片/文档内容相似**与**视频视觉相似**三种扫描模式，默认只保留**创建时间最晚**的一份；先出报告，人工核对、两次确认后才删除，默认移入群晖回收站，并持久化操作日志。图片/文档相似结果必须人工复核、禁止一键批量删除；视频相似组默认不勾选，允许手动全选批量删除。另附字幕（云端 ASR/LLM）、下载（直链/HLS）、格式转换与音视频合成四个独立模块。

> **当前代码版本：1.1.0-0059（已打包 / 未发布）**（2026-11-17）—— 新增「合成」页：把视频片段与音频片段按选择顺序拼接、混流为一个文件（内置功能，无启用开关）；软件显示名改为「重复文件清理与影音工具 / Duplicate Cleaner & Media Toolkit」（包 ID 与数据目录不变）。
> 最近一次正式发布仍为 [v1.1.0-0050](https://github.com/yitianfadi/synology-duplicate-cleaner/releases/tag/v1.1.0-0050)；v0051–v0059 的说明见 [发布说明](docs/RELEASE_NOTES_v1.1.0-0059.md)。

> ## ⚠️ 风险提示
> **删除文件存在数据丢失风险，重要数据建议先备份；本工具仅基于哈希判定重复，无法保证业务文件适用性，请核对扫描结果再操作。**
>
> **图片/文档相似为特征比对结果，存在误匹配概率，必须人工复核、禁止一键批量删除。视频视觉相似误判率更高：默认不勾选，即使使用“全选视频相似组副本”批量删除，也必须人工核对保留视频并完成两次确认。**
>
> 套件以 DSM 系统内部用户 `duplicatecleaner`（非 root）运行。首次使用需在“控制面板 → 共享文件夹 → 权限 → 系统内部用户”中给该用户授予目标文件夹读取/写入权限；仅扫描可只给读取，删除副本需要写入。请只在可信局域网使用，不要将 8787 端口暴露到公网。

## 功能

**扫描与判重**

- 文件夹选择器：共享文件夹/子目录多选，可加排除目录
- **精准模式（默认）**：大小 → 头尾采样指纹 → 全量 SHA-256/MD5，内容完全一致才算重复（文件名不参与）；大库分页/搜索/排序走 SQLite（FTS5 trigram 10 万明细 P95 ≈ 80 ms，不可用时自动回退 LIKE）
- **内容相似模式**：文本/PDF/DOCX/ODT/PNG 等特征向量 + MinHash/感知哈希，阈值 0–100% 可调；与精准组分开展示
- **视频视觉相似（默认关闭）**：内置 FFmpeg（x86_64/aarch64），按总时长抽 5–100 帧生成时序 pHash 并用 DTW 比较；独立分区、默认不勾选；指纹 SQLite 缓存、独立并发，硬解模式 `auto/off/vaapi/qsv/nvdec/videotoolbox`，可配置外部 FFmpeg 绝对路径
- **保留策略**：最晚/最早创建、指定路径（优先 `statx` btime；无创建时间时整组按 mtime 选择并标记）；**保留规则链（v0043）** 追加 mtime/atime、体积、路径优先级、文件名通配符/正则、内嵌字幕/音轨优先，按序比较、平局转人工
- **增量扫描（v0043）**：跨扫描哈希缓存（SQLite `hash_cache`，键 dev+inode），`size/mtime_ns` 未变即复用 quick/full 哈希，第二次扫描几乎不再读盘；结果标注「本次新增/内容变化」并可只看增量。枚举仍会 stat 全部文件
- **排除规则（v0043）**：文件名正则/通配符、`.ignore`（gitignore 常用子集）、大文件头+中+尾三段采样；影视库里与视频同名的字幕/海报/nfo 默认不参与判重（照片库不受影响）
- **缓存管理（v0043）**：设置页显示增量哈希/媒体探测缓存条目，可一键清理（只清缓存，不动扫描结果）

**结果、预览与删除**

- 分组报告：路径、大小、完整哈希、创建/修改时间、匹配类型、相似度；保留项高亮；支持预览与导出 CSV
- **预览增强（v0044）**：视频缩略图条（点图跳到对应时间点播放）、媒体信息（时长/分辨率/编码/音轨数/字幕轨数）、同组两文件并排对比（同步播放可开关）；视频改为 Range 流式播放，不再先下载整个文件
- **删除白名单（v0044）**：按后缀/目录/文件名正则/视频附属文件保护，命中项不可勾选；删除计划与执行前各再校验一次
- **硬链接合并（v0045，默认关闭）**：把精准重复组的非保留项替换为指向保留项的硬链接（路径都在、内容共享、空间释放）；逐组确认 + 二次确认，仅同文件系统；可「恢复为独立副本」（Btrfs FICLONE）
- **套件独立回收站（v0045）**：删除去向可选共享文件夹 `#recycle` 或套件回收站 `#duplicate-cleaner-trash`（同卷 rename），按批次记录清单，支持整组恢复与输入「永久删除」清理
- **强安全删除**：报告 → 人工核对 → 二次确认 → 服务端逐文件重校验（存在性/大小/mtime/inode/哈希）→ 默认进回收站 → 审计日志；图片/文档相似组默认不勾选、禁止组级全选，必须人工逐组复核；视频组默认不勾选但允许手动全选，仍需两次确认

**自动化**

- **计划扫描（v0046）**：`daily 03:30` / `weekly mon,wed 04:00` / `interval 360` 规则后台触发；可设 1 分钟负载阈值，负载超标或已有扫描在跑时跳过本次
- **通知（v0046）**：扫描完成/失败、字幕批次结束、失败数超阈值、单次释放空间达阈值时推送 **DSM 系统通知 / Webhook / Telegram**；可逐渠道发送测试，Token 不回显

**字幕**

- **云端字幕（实验，默认关闭）**：OpenAI 兼容 ASR + LLM 翻译；FFmpeg 抽音频、自动分块、SRT/VTT/双语字幕；可拉取 `/models`、一键测试 ASR/LLM 连接；也可指向局域网 [WhisperLiveKit](https://github.com/QuentinFuxa/WhisperLiveKit) 做本地 ASR（见 [字幕契约 §9](docs/SUBTITLE_CONTRACT.md)）
- **目录批量字幕（v0028）**：字幕页选目录递归枚举视频批量提交；`.srt` 直接写入视频同目录（Plex/Emby 可识别），已有同名 srt 默认跳过、绝不覆盖；对已有 srt 可「只翻译」；写回失败标记警告但可下载；批次支持暂停/继续/取消/重试，「批次总览」可随时切回旧批次
- **步骤时间线 / 分片预取（v0038/v0040）**：任务详情记录排队→探测→抽音频/识别→翻译→写盘各段耗时与分片明细；识别当前分片时后台预取下一片，设置页可关闭
- **失败智能处理（v0048）**：失败按音频提取/无语音/超时/码流/权限/网络/云端/内部归类，可恢复错误自动退避重试、无语音自动跳过；失败清单可导出 CSV，支持单条/批量/强制重试
- **调度与音轨（v0048）**：负载阈值超标时暂停取新任务、目录优先级 + 任务置顶、ETA 校准；可按序号/语言指定音轨，避免误识别配音轨
- **目录监控（v0048）**：监控目录内新增视频自动入队并按设置生成/翻译字幕，按文件大小 + mtime 去重
- **批次组取消/删除（v0050）**：大批次组取消异步化（立即返回、进度可见，不再超时或误启新任务）；总览支持删除，进行中可「强制取消并删除」；任务明细可取消剩余/当前筛选、下滑自动加载，已取消任务独立页签

**下载（v0051）**

- **直链 / m3u8 下载**：粘贴地址（每行一个）批量入队，可单个下载；直链支持 Range 断点续传，m3u8 支持 TS / fMP4 / 多码率 / 独立音轨，AES-128 加密流交给内置 FFmpeg 解密并无损合并为 MP4
- **队列与并发**：任务级并发 1–4（默认 2，超出排队）与单任务分片并发 1–16（默认 4）可设；支持暂停/继续/取消/重试/删除，批量组可整组操作；全局限速与剩余空间闸门
- **落盘规则**：下载目录用共享文件夹选择器挑选（不写死），可按站点/日期/站点+日期/自定义模板分子目录；临时分片与产物先写 `*.dcpart` 再原子改名（同卷、不跨卷搬运），完成后自动清理临时目录，失败保留以便续传
- **防盗链与登录态**：可配置 User-Agent / Referer / Cookie / 代理；Cookie 只写不读，不进日志
- **播放网页解析（v0052）**：给一个网页地址即可静态提取里面的 m3u8 / 直链候选（`<video>`/`<source>`/`data-*`、社交卡片、JSON-LD、播放器脚本文本），候选带「是否真是播放列表」校验；JS 渲染/需登录的页面可用「粘贴网页源码」或浏览器「Copy as cURL」兜底，cURL 里的 Referer/Cookie 只在服务端暂存 15 分钟并只用于随后提交的下载任务
- **安全默认**：拒绝内网/回环地址（SSRF）、拒绝带账号密码的 URL、输出目录必须落在共享文件夹内；明确不支持 DRM 与直播
- **下载前去重（v0053）**：目标文件已存在且体积一致时直接跳过（不消耗流量）；可关
- **自动重试（v0053）**：网络/分片类错误自动退避重排（次数 0–5 可设），DRM/地址非法等确定性错误不重试
- **分时限速（v0053）**：低谷时段（支持跨零点）用另一档限速，白天走常规限速
- **文件名模板（v0053）**：`{title}/{site}/{date}/{height}/{season}/{episode}…`，自动识别 `S01E02` 与「第二季第三集」
- **队列操作（v0053）**：任务置顶、全部暂停/继续、重试失败、导出 CSV；任务列表显示下载目录剩余空间
- **书签脚本（v0053）**：在播放页一键把当前地址发到 NAS 下载页并自动解析
- **DASH 支持（v0054）**：`.mpd`（SegmentTemplate/SegmentTimeline/SegmentList/SegmentBase）下载音视频轨并合并为 MP4；含 `ContentProtection` 的 DRM 清单直接拒绝
- **订阅下载（v0054）**：RSS/Atom 或播放网页按间隔检查新条目自动入队，已下载地址不重复；可手动「立即检查」
- **完成后联动（可选）**：自动入队扫描该目录、自动提交字幕任务

**格式转换（v0056）**

- **预设驱动**：16 个预设覆盖视频互转（MP4 H.264/H.265、MKV、WEBM VP9、MOV、TS、AVI）、音频互转（MP3/AAC/FLAC/WAV/OGG/OPUS）与「只换封装」（MKV/MP4 copy，秒级、无损）
- **换容器 vs 重编码**：页面明确区分；copy 预设只重写容器，重编码预设按质量三档映射 CRF、可选编码速度/分辨率上限/立体声
- **队列与进度**：并发 1–2（默认 1）、实时进度/速度/fps/ETA、取消/重试/删除产物、批量取消/重试失败/清理、CSV 导出；重启后运行中任务回到队列
- **安全默认**：默认输出到源目录并自动改名（`名称 (2).ext`），绝不覆盖原文件；「转换成功后删除源文件」需逐次二次确认且产物校验通过才执行；输出目录必须在共享文件夹内
- **空闲时段**：可只在夜间执行转换，窗口外任务排队等待，避免与字幕/下载抢 CPU 与磁盘 IO
- **批量选择**：目录递归枚举（按音视频后缀过滤）或手动粘贴路径，提交前可见已选列表与总体积

**音视频合成（v0059）**

- **按选择顺序拼接**：视频片段与音频片段各一个有序列表，顺序即输出顺序；视频拼成画面、音频拼成声音后混流
- **两种路径**：同编码/同分辨率时直接拷贝（秒级）；参数不一致时自动统一转码（scale/fps/48k 立体声 AAC），也可强制 `copy`/`encode`
- **时长规则**：以视频总时长为准，音频不足静音补齐、超出截断；`mp4/mkv` 容器可选，默认 `mp4`
- **安全**：源文件必须在共享内、拒符号链接；产物校验通过才原子改名；「成功后删除源文件」需逐次确认
- **内置功能**：无启用开关，装好即可用；默认参数在「设置 → 合成」

**任务与运维（v0057：任务中心已并入各模块）**

- **内嵌标签**：「扫描」页 = 扫描 / 历史 / 删除与回收站；「字幕」页 = 提交 / 任务；「设置」页 = 常规 / 操作日志。深链 `#/scan?tab=history`、`#/subtitles?tab=jobs`、`#/settings?tab=logs`
- **任务检索与批量操作（v0049）**：字幕任务按状态/路径/目录/后缀/失败分类筛选；支持全选、批量取消/重试/置顶
- **权限与路径体检（v0049）**：一键只读检查配置目录与共享文件夹的可读/可写状态，汇总扫描/字幕权限异常并给出 DSM 操作指引（不做自动提权）
- **日志（v0049）**：按任务 ID/关键字检索日志与审计，一键导出可读文本；操作日志支持勾选删除或只保留最近 N 天
- **即将执行队列（v0039）**：字幕任务按真实 FIFO 顺序显示将执行的排队任务（含队列位置/总数），并单列「已暂停」「最近完成」
- **导航结构（v0057）**：顶部为「扫描 / 字幕 / 下载 / 转换」，设置移到右上角；旧 `#/history`、`#/logs` 书签不再重定向（按需求）
- 扫描可暂停/继续/停止；精准/相似并发、哈希限速、特征缓存、低优先级（nice/ionice）；跳过符号链接、空文件、隐藏/系统文件与自定义后缀；扫描历史与操作日志持久化可下载
- 前端为 ES modules（`app.js` 入口 + `js/` 模块），无构建、无第三方依赖；静态检查包含模块图与无头浏览器冒烟

## 快速开始

### 1. 构建 SPK（开发机）

```bash
python build/fetch_ffmpeg.py   # 首次构建：下载两个架构的静态 FFmpeg 到 vendor/ffmpeg/
python build/build_spk.py
# 生成 dist/DuplicateCleaner-1.1.0-0059.spk
```

构建机需要 Python 3.8+；FFmpeg 二进制不提交到 Git，首次构建需运行 `build/fetch_ffmpeg.py`。重新生成图标需要 Pillow（仓库已带 PNG，可 `--no-icons`）。

### 2. 安装到 DSM

1. DSM 套件中心先安装 **Python3**（3.8+）。
2. 套件中心 → 手动安装 → 选择 `dist/DuplicateCleaner-1.1.0-0059.spk`。
3. 启动套件；从 DSM 主菜单打开“重复文件清理与字幕”，或访问 `http://<NAS>:8787/`。
4. 使用 administrators 组账号登录。
5. 按页面黄色“权限提示”给 `duplicatecleaner` 系统内部用户授权目标共享文件夹（读取；删除副本需读取/写入）。

详细步骤、权限、TLS、排错见 [打包与部署](docs/SPK_PACKAGING.md)。

### 3. 本地开发联调（Windows/Linux/macOS）

不需要 DSM 也可以跑通完整流程（开发模式，仅用于本机测试）：

```bash
# PowerShell
$env:DUP_CLEANER_DEV="1"
$env:DUP_DEV_ROOTS="D:\tmp\dup-test;D:\tmp\dup-test2"
$env:DUP_DEV_PASSWORD="admin"
python src/backend/app.py --host 127.0.0.1 --port 8787 --data-dir ./data --web-dir ./src/web
```

浏览器打开 `http://127.0.0.1:8787/`，账号 `admin` / 密码 `admin`（或 `DUP_DEV_PASSWORD`）。
开发模式只在环境变量显式开启时生效，SPK 启动脚本会主动 `unset` 相关变量。

### 4. 测试

```bash
cd src/backend
python -m unittest discover -s tests -v

# 前端模块语法/图与静态验收
node qa/check_web_modules.mjs
python qa/static_checks.py --skip-tests

# 浏览器冒烟（无头 Chromium；本机无浏览器时自动 SKIP）
python qa/web_smoke.py

# 100k 明细路径搜索基准（FTS5 vs 强制 LIKE）
python qa/bench_search.py
```

验收脚本与报告见 `qa/`（集成测试、需求逐项对照、SPK 结构检查）。

## 安全设计摘要

1. **绝不自动删除**：扫描完成只生成报告；删除需要用户选文件 → 生成计划 → 第一次清单确认 → 第二次最终确认。
2. **服务端二次校验**：删除前重新检查文件存在、大小/mtime/inode/dev 未变、保留文件仍在；精准组要求候选与保留文件全量哈希一致，相似组要求各自内容哈希与扫描记录一致。
3. **路径白名单/黑名单**：只允许共享文件夹子树；禁止系统目录、`@*`、`#recycle`、`#snapshot`、`@eaDir` 等。
4. **不跟随符号链接**；硬链接按 inode 去重，避免“删了不释放空间”。
5. **默认回收站**：移动到 `<共享文件夹>/#recycle/@duplicate-cleaner/<时间>/<相对路径>`；永久删除需额外输入“永久删除”。
6. **相似模式门禁**：图片/文档相似组默认不勾选、无组级全选、必须人工逐组复核并逐条选择；删除计划需 `confirm_similar=true` + 已复核组 ID。视频组默认不勾选，但允许手动全选批量进入计划；视频删除不走相似复核门禁，仍需两次确认。
7. **认证与审计**：DSM 管理员登录（`SYNO.API.Auth`），HttpOnly Cookie + CSRF；审计日志持久化。
8. **下载安全（v0051）**：只允许 http/https 且拒绝 URL 内嵌凭据；默认拒绝内网/回环地址（SSRF 防护）；输出目录必须落在共享文件夹内；Cookie 属密钥键，只写不读、不进日志；明确不做 DRM 绕过。

## 已知限制

**运行环境与权限**

- DSM 7 不预装 Python 3，需先从套件中心安装 Python3；套件以非 root 用户 `duplicatecleaner` 运行，必须给目标共享文件夹授权（只读即可扫描，删除/写回需要写权限），未授权时页面会提示权限不足
- 加密共享文件夹需先在 DSM 中解锁，否则扫描/删除会失败
- 默认 HTTP 仅适合可信局域网；公网/远程请用 VPN 或反向代理 + TLS。页面必须经后端 HTTP 打开（`http://<NAS>:8787/`），不能双击本地 `file://` 页面（ES modules 受 CORS 限制）
- 单次扫描默认最多 500,000 个文件，超大库建议分目录扫描

**判重与保留**

- 创建时间依赖 `statx` 的 btime；文件系统不支持时整组按 mtime 选择并在报告里警示，仍需人工核对
- 精准组只保证内容哈希一致，相似组只保证特征相似，本工具不判断业务语义，任何删除都需人工确认
- 相似模式不联网、不上传文件；未安装 Pillow 时 JPEG 感知哈希降级为字节特征（置信度低）；默认跳过压缩包/媒体/可执行/超大文件（这些文件仍参与精准匹配）
- 增量扫描只是复用哈希：枚举仍会 stat 全部文件；`dev/inode/size/mtime_ns` 未变才复用，文件被原地修改而 mtime 不变的极端情况无法感知（删除前仍会全量重校验）
- 保留规则链按序比较，平局转人工；DSM 默认 `relatime` 下 atime 不可靠，仅作参考；精准组内文件大小相同，所以"体积最大/最小"规则只对相似/视频组有意义
- `.ignore` 只实现 gitignore 常用子集，不支持 `**` 等完整语法；影视附属文件只跳过与同目录视频同源的子集/海报/nfo，不按后缀无差别跳过
- 删除白名单默认只保护字幕与元数据后缀，不含图片；海报/剧照靠"同目录同源视频附属文件"保护，照片库中与视频无关的图片仍正常判重

**视频**

- 视频相似需开总开关，单视频解码较慢；SPK 内置 FFmpeg 4.1 静态构建，硬解能力取决于机型/内核，不可用时自动回退软解并标记 `hwaccel_fallback`；外部 FFmpeg 必须是存在且可执行的绝对路径
- 不支持剧情语义、剪辑乱序、换脸/重绘伪原创；片段与完整长视频的匹配不承诺；也不承诺识别"不同剪辑版本"，相似度分档仅供参考，最终人工复核
- 升级到 v0047 后首次扫描会一次性重算全部视频指纹（算法版本升级），建议在低峰期执行
- 缩略图首次生成需解一帧（4K 可能 1–2 秒）；浏览器不支持 HEVC/MKV/DTS 时视频无法播放（缩略图仍可见），本工具不提供在线转码
- 硬链接合并只对精准组、同文件系统生效，跨卷自动跳过；合并后任一路径修改都会影响其他路径，回收站恢复也不会得到独立第二份 inode（可用「恢复为独立副本」撤销）
- 套件回收站恢复到原位置时遇同名文件会跳过、绝不覆盖；清理需输入「永久删除」，且只删除清单内文件
- 语音识别为可选外部命令（默认关闭，不内置模型）；未配置时视频扫描仍按视觉指纹完成，不会失败

**字幕**

- 云端字幕默认关闭；启用后音频与字幕文本会发送到所配置的服务，API Key 保存在 `<var>/settings.json`，接口不返回明文。ASR 模型须返回带时间戳的 `verbose_json` 片段或 SRT，纯文本模型无法生成字幕
- 「获取模型列表」依赖服务端实现 `GET /models`，未实现时给出提示并允许手填；列表最多 500 条、不做能力过滤。「测试连接」会发送最小测试数据（约 1 秒静音 MP3 / 1 条短文本），通过不代表字幕质量
- 本地 ASR 可选 WhisperLiveKit（独立服务，Python 3.11+/torch，不打包进 SPK）；本地翻译需另配 OpenAI 兼容 LLM
- 目录批量字幕只写 `.srt`（不向视频旁写 vtt），已有同名 srt 只跳过、不提供覆盖开关；「只翻译已有字幕」只识别视频同目录 `<视频名>.srt`；不支持说话人分离、人工校对或对已有译文重译
- 单批最多 500 个视频、单次提交或枚举最多 20000 个，已完成任务保留上限 200 条；超过上限的旧任务会被清理
- 自动重试只覆盖超时/网络/云端/内部错误（无语音、权限、码流不重试）；目录监控为轮询实现（无 inotify），按大小 + mtime 判断新增；负载阈值用 1 分钟 loadavg（Windows 调试环境视为不限制）
- 计划扫描为后台轮询（标准库无 cron）：触发时已有扫描、负载超阈值或无可用目录则跳过且不补跑；套件停止或 NAS 休眠期间不触发
- 通知：DSM 系统通知需 `synodsmnotify`（非 DSM 环境自动跳过）；Webhook/Telegram 需 NAS 能出网；Bot Token 不回显、不写日志
- 权限体检只做只读检测并给 DSM 操作指引，不自动提权；日志检索最多扫描 500 个日志文件、单文件读取 512KB
- 批次组取消运行中的任务会等待当前 ASR 分片/翻译请求结束（显示「取消中」），不会立即 kill；强制删除会先取消再删除，删除后不可恢复（含临时分片与产物）

**下载**

- **内置功能，无需开启**（v0058 起不再有启用开关，仅管理员可用）；只支持**点播**内容，直播/滚动播放列表（无 `EXT-X-ENDLIST`）直接拒绝
- 不支持 DRM（Widevine/FairPlay/PlayReady）与 SAMPLE-AES，不做任何绕过；HLS 自动解密仅覆盖 AES-128
- 不内置浏览器、不执行 JS：需要 JS 渲染或 Cloudflare 挑战的播放页无法自动解析；v0052 起可把页面源码或浏览器「Copy as cURL」粘贴到下载页解析，仍不会执行脚本
- 合并为 MP4 采用 `-c copy` 无损封装；失败时只尝试一次音频转 AAC，不做完整转码（NAS 上转码很慢）
- 下载会与扫描/字幕抢磁盘 IO：NAS 磁盘忙时建议任务并发 1–2，并给全局限速设置一个上限
'- 失败任务会保留 `.dc-download-<job_id>` 临时目录以便续传，需手动删除或在任务行「删除」
'- 「下载前去重」按最终文件名 + 体积判断：改过文件名模板后历史文件不会自动匹配；分时限速在任务开始时判定，长任务不会中途换档
- DASH 只支持单 Period（多 Period 只取第一个），不支持字幕轨与加密 DASH；订阅只做一层页面解析，不做站内爬取，登录态不跨检查持久化''

**升级与数据**

- v0012 起扫描/组/文件/删除任务/特征缓存/字幕任务元数据存放在 `<var>/dupcleaner.sqlite3`，设置、审计、运行日志、字幕文件仍是文件；升级或备份时请把整个 `var/` 一起备份
- v0014 起支持升级前自动暂停并写断点，升级后需在「扫描历史」里手动「继续扫描」；删除任务不会续跑
- SQLite 元数据 schema 当前为 **v9**（v0025 引入 v5 起逐版升级；打开旧库自动迁移，不支持降级），升级/回退前请备份整个 `var/`；`scan_files` 不再冗余 payload，FTS5 trigram 不可用时自动回退 LIKE，搜索词少于 3 字符始终走 LIKE
