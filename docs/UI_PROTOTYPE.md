# 前端页面原型说明

> 对应实现：`src/web/index.html`、`src/web/app.js`、`src/web/styles.css`  
> 设计目标：在 DSM 7 的浏览器环境中，用最少认知成本完成“选目录 → 看报告 → 核对 → 两次确认删除”的高风险操作。
> 风格：DSM 管理界面式的浅色、紧凑、信息密度高；中文文案；无第三方 UI 框架/CDN。

## 1. 信息架构

```
登录页
└── 主应用
    ├── 扫描（默认）
    │   ├── 扫描范围（根目录 / 排除目录）
    │   ├── 扫描选项（哈希、保留策略、过滤、性能）
    │   ├── 进度（运行中）
    │   └── 结果报告（扫描完成后）
    │       ├── 摘要卡片
    │       ├── 工具栏（搜索/全选/CSV/删除）
    │       └── 重复组列表（分页）
    ├── 历史记录（每次扫描）
    ├── 操作日志（审计事件 + 日志下载）
    └── 设置（默认参数）
```

顶部**常驻风险提示条**在所有页面显示，不可关闭：

> 删除文件存在数据丢失风险，重要数据建议先备份；本工具仅基于哈希判定重复，无法保证业务文件适用性，请核对扫描结果再操作。

交互：
- “选择文件夹”打开弹窗；支持共享根懒加载、当前层搜索、面包屑、多选。
- 根目录与排除目录用同一棵树；已选为根的子目录不能再作为排除项添加（避免自相矛盾）。
- 表单校验在前端先做（大小区间、后缀格式、并发 1–8），后端再次校验。
- 开始扫描后按钮禁用，页面切到进度卡片；`SCAN_BUSY` 时提示已有扫描。

- 排除模式复用同一组件，标题变为“添加排除目录”，不可选择已选根目录外的路径。

### 2.4 扫描进度

```
┌─ 扫描进行中 ────────────────────────────────────────────────────────┐
│ 阶段：计算文件哈希            已用 00:42        [暂停] [停止]        │
│ ██████████████████████████░░░░░░  68%                                │
│ 文件 12,430 / 18,200   重复组 34   候选 1,203   读取 1.8 GB (43 MB/s)│
│ 当前：/volume1/photo/2024/IMG_0231.RAW                               │
│ 提示：扫描可随时暂停/停止；停止后已发现结果仍可查看。                 │
└─────────────────────────────────────────────────────────────────────┘
```

- 阶段映射：枚举目录 → 按大小分组 → 快速指纹 → 全量哈希 → 生成报告。
- 暂停后按钮变“继续”；停止需要确认；停止状态显示“已停止，可查看部分结果”。
- 轮询失败/离线：显示“连接中断，正在重试”，退避后继续；不发删除请求。

```
│   └────────────────────────────────────────────────────────────┘   │

│   ( ) 选择保留：/volume1/…/a.jpg   ( ) /volume1/…/b.jpg             │
└──────────────────────────────────────────────────────────────────────┘
```

- **保留项高亮**：绿色左边框 + “保留”徽标；复选框禁用，不能勾选删除。
- 文件行展开可看完整哈希（默认截断显示，点击复制完整值）；创建时间后的图标/文字标注来源：
  - `statx`：文件系统创建时间；
  - `ctime`：降级值，红色警示（默认不会出现）；
  - `unknown`：未知，组转人工。
- 需人工组：顶部黄色警示；**v1 禁止删除**（创建时间不可靠时，用户认为的保留项可能与服务端不同，避免误删）；组内复选框全部禁用，显示“该组创建时间无法可靠区分，已禁止自动删除；请先在 DSM 中人工确认保留项，本组不参与本次清理”。全选操作跳过这些组。
- 组级“全选副本”只选非保留、非人工未决的行；全局“全选待删除副本”通过 `scope=all_duplicates` 实现，避免分页只选当前页。
- 搜索/排序在前端对已加载组过滤，或带参数请求后端；分页每次 100 组，“加载更多”。
- CSV 下载使用同源 GET（Cookie 鉴权），文件名含扫描 ID。

```
┌─ 最终确认 ─────────────────────────────────────────────── [×] ┐

│                                                              │

│                                                              │

```

- 第一步先调用 `POST /api/scans/{id}/delete-plan`，展示服务端重校验后的实际清单与跳过项；
  用户改变“回收站/永久”选项时重新生成计划。
- 第二步中的 `DELETE` 是 UI 防误触；请求体还会带 `confirm:"DELETE"`，后端强制校验。
- 永久删除：额外输入“永久删除”，按钮红色；否则禁用。
- 执行中按钮全部禁用，展示进度条/逐文件结果；关闭弹窗不取消任务，可从历史查看结果。

### 2.7 历史记录 / 操作日志 / 设置

- **历史记录**：扫描时间、范围、保留策略、状态、组数/副本数/可释放空间；操作“查看结果 / 导出 CSV”。
- **操作日志**：审计事件（登录、扫描开始/结束、删除计划、逐文件删除）时间线；日志文件列表与下载；提示数据目录 `/var/packages/DuplicateCleaner/var`。
- **设置**：默认哈希、保留策略、过滤、并发/限速、回收站默认值；保存后只影响新扫描。永久删除不可设为默认。

## 3. 状态与错误处理

| 场景 | UI 行为 |
|---|---|
| 会话过期 401 | 清空内存状态，回登录页，提示“会话已过期，请重新登录” |
| 扫描忙 SCAN_BUSY | Toast 提示并跳转到当前运行扫描 |
| 扫描失败 | 进度卡片红色错误、可展开日志；提供“重新扫描” |
| 文件夹无权限 | 选择器中禁用并显示原因；不弹系统错误 |
| 删除计划过期 | 提示重新生成计划，回到第一步 |
| 删除部分失败 | 结果页区分成功/跳过/失败，可下载日志；不隐藏失败 |
| 网络断开 | 轮询指数退避，顶部状态“连接中断”；恢复后继续，不重复提交删除 |
| 空结果 | 显示“未发现重复文件”并建议调整过滤条件，不显示删除按钮 |

## 4. 交互与可访问性

- 所有弹窗：焦点进入弹窗、Tab 循环、Esc 关闭（删除执行中不可关闭）、遮罩点击不关闭高风险弹窗。
- 表格/组卡片使用语义化 `button`、`checkbox`、`aria-label`；保留项用文字 + 颜色双编码，避免只靠颜色。
- 时间统一显示 NAS 本地时区（后端 ISO 带偏移）；大小使用 KB/MB/GB（1024 进制）。
- 哈希默认显示前 12 + 后 8 字符，复制完整值；不把长哈希撑破布局。
- 所有服务端文本用 `textContent` 渲染，禁止把文件路径/哈希插入 `innerHTML`。
- 操作按钮有 loading/disabled 状态，防止重复提交；危险按钮与普通按钮视觉区分。

## 5. 与后端接口的映射

| 页面动作 | 接口 |
|---|---|
| 登录/恢复会话/退出 | `POST /api/auth/login`、`GET /api/auth/me`、`POST /api/auth/logout` |
| 共享列表/目录树 | `GET /api/shares`、`GET /api/browse` |
| 设置 | `GET/PUT /api/settings` |
| 开始扫描 | `POST /api/scans` |
| 进度/暂停/继续/停止 | `GET /api/scans/{id}`、`POST …/pause|resume|stop` |
| 结果分页 | `GET /api/scans/{id}/groups` |
| CSV | `GET /api/scans/{id}/csv` |
| 预览 | `GET /api/preview?path=…` |
| 删除计划/执行/结果 | `POST …/delete-plan`、`POST …/delete`、`GET …/delete/{job_id}` |
| 历史/审计/日志 | `GET /api/scans`、`GET /api/logs`、`GET /api/logs/download` |

## 6. 验收要点

1. 风险提示在登录后所有页面常驻，且文字与需求完全一致。
2. 扫描前必须至少选择一个根目录；排除目录必须在根目录内。
3. 结果中保留项不可勾选删除；需人工组 v1 禁止删除，需在 DSM 中人工处理。
4. 删除必须经过“清单确认 + 最终确认”两个弹窗；永久删除必须输入“永久删除”。
5. 删除请求失败/计划过期时不得静默重试删除。
6. CSV 带 BOM，Excel 打开中文不乱码。
7. 窄屏下仍可完成扫描、查看结果、两次确认。
