# 前端页面原型说明

> 对应实现：`src/web/index.html`、`src/web/app.js`、`src/web/styles.css`  
> 设计目标：在 DSM 7 的浏览器环境中，用最少认知成本完成“选目录 → 看报告 → 核对 → 两次确认删除”的高风险操作。
> 风格：DSM 管理界面式的浅色、紧凑、信息密度高；中文文案；无第三方 UI 框架/CDN。

## 1. 信息架构

```
登录页
└── 主应用
    ├── 扫描（默认）
    │   ├── 扫描范围（根目录 / 排除目录）
    │   ├── 扫描选项（哈希、保留策略、过滤、性能、视频相似）
    │   ├── 进度（运行中）
    │   └── 结果报告（扫描完成后）
    │       ├── 摘要卡片
    │       ├── 工具栏（搜索/全选/CSV/删除）
    │       └── 重复组列表（分页）
    ├── 字幕（目录批量生成/翻译，v0028）
    │   ├── 选择目录（复用扫描范围选择器）
    │   ├── 视频列表（筛选/勾选）
    │   ├── 任务选项（语言/译文/跳过已有）
    │   └── 批次进度（暂停/继续/取消/重试）
    ├── 任务中心（v0038：扫描历史 / 字幕任务 / 删除任务 / 操作日志）
    └── 设置（右上角入口；默认参数 + 云端字幕 + 系统·存储与运行诊断）
```

顶部**常驻风险提示条**在所有页面显示，不可关闭：

> 删除文件存在数据丢失风险，重要数据建议先备份；本工具仅基于哈希判定重复，无法保证业务文件适用性，请核对扫描结果再操作。

- **保留项高亮**：绿色左边框 + “保留”徽标；复选框禁用，不能勾选删除。
- 文件行展开可看完整哈希（默认截断显示，点击复制完整值）；创建时间后的图标/文字标注来源：
  - `statx`：文件系统创建时间；
  - `ctime`：降级值，红色警示（默认不会出现）；
  - `unknown`：未知；该组整组按修改时间选择保留项，并显示“无创建时间 · 按修改时间保留”警示。
- **修改时间回退组**：顶部/组内显示黄色警示“无创建时间 · 按修改时间保留”；非保留项仍可勾选/全选，但删除向导会提示人工核对。可信 btime 相同等无法判断的组仍按原规则禁止自动删除。
- 组级“全选副本”只选非保留、非人工未决的行；全局“全选待删除副本”通过 `scope=all_duplicates` 实现，避免分页只选当前页。
- 搜索/排序在前端对已加载组过滤，或带参数请求后端；分页每次 100 组，“加载更多”。
- CSV 下载使用同源 GET（Cookie 鉴权），文件名含扫描 ID。

### 2.7 任务中心（含操作日志）/ 设置

- **任务中心**（v0038：操作日志从独立导航并入此处）：扫描历史 / 字幕任务 / 删除任务 / 操作日志四个标签页。
- **扫描历史**：扫描时间、范围、保留策略、状态、组数/副本数/可释放空间；操作“查看结果 / 导出 CSV”。
- **操作日志**：审计事件（登录、扫描开始/结束、删除计划、逐文件删除、日志清理）时间线，支持勾选删除、只保留最近 N 天；日志文件列表、下载与删除；提示数据目录 `/var/packages/DuplicateCleaner/var`。
- **设置**（v0038：右上角入口）：默认哈希、保留策略、过滤、并发/限速、回收站默认值；保存后只影响新扫描。永久删除不可设为默认。另有「云端字幕」分组（ASR/LLM、模型列表与连接测试、音频来源 nas/server、字幕并发任务数 1–4（默认 1，**保存后立即生效**）、任务目录 VTT 可选生成（默认关）、译文输出组合（译文+双语/只写译文/只写双语，默认译文+双语）、目录批量默认输出方式 / 跳过已有 / 任务保留上限；本地推理模型可勾选「禁用 LLM 思考」提速；ASR 识别语言/翻译目标语言下拉覆盖常见 19 种语言码）与「系统 · 存储与运行诊断」（v0038 从任务中心移入：数据库/表行数/缓存/媒体/密钥状态/备份与维护）。
- **字幕任务详情（v0038）**：新增「步骤耗时」表（排队/媒体探测/音频提取+识别/翻译/写盘，含开始、结束、耗时、明细），可展开 ASR 分片与翻译批次明细；任务列表显示总耗时。

## 3. 状态与错误处理

| 场景 | UI 行为 |
|---|---|
| 会话过期 401 | 清空内存状态，回登录页，提示“会话已过期，请重新登录” |
| 扫描忙 SCAN_BUSY | Toast 提示并跳转到当前运行扫描 |
| 扫描失败 | 进度卡片红色错误、可展开日志；提供“重新扫描” |
| 文件夹无权限 | 选择器中禁用并显示原因；不弹系统错误 |
| 删除计划过期 | 提示重新生成计划，回到第一步 |
| 删除部分失败 | 结果页区分成功/跳过/失败，可下载日志；不隐藏失败 |
| 网络断开 | 轮询指数退避，顶部状态“连接中断”；恢复后继续，不重复提交删除 |
| 空结果 | 显示“未发现重复文件”并建议调整过滤条件，不显示删除按钮 |
| 字幕枚举为空 | 显示“该目录下没有视频文件”，不显示提交按钮 |
| 字幕写回失败 | 任务列表/详情显示警告（视频目录不可写/部分失败），任务目录文件仍可下载 |
| 已有字幕 | 任务标记“已跳过”，不覆盖、不重复调用 ASR；详情说明跳过原因 |
| 提交按钮禁用 | 按钮下方常显原因（未选视频 / 未勾确认项 / 超过 20000 个 / 未配置凭据）；全选不截断，提示“将分为 M 批” |
| 大批量 | 一次提交 ≤20000 个视频，后端按每批 ≤500 自动拆批；进度卡显示组聚合进度、批次列表与任务明细分页；暂停/继续/取消/重试作用于整组 |
| 删除后结果 | 删除完成后结果页自动重置并重拉：已删除文件不再显示、整组消失、统计/分区计数同步；当前页删空自动回退上一页 |

## 4. 交互与可访问性

- 所有弹窗：焦点进入弹窗、Tab 循环、Esc 关闭（删除执行中不可关闭）、遮罩点击不关闭高风险弹窗。
- 表格/组卡片使用语义化 `button`、`checkbox`、`aria-label`；保留项用文字 + 颜色双编码，避免只靠颜色。
- 时间统一显示 NAS 本地时区（后端 ISO 带偏移）；大小使用 KB/MB/GB（1024 进制）。
- 哈希默认显示前 12 + 后 8 字符，复制完整值；不把长哈希撑破布局。
- 所有服务端文本用 `textContent` 渲染，禁止把文件路径/哈希插入 `innerHTML`。
- 操作按钮有 loading/disabled 状态，防止重复提交；危险按钮与普通按钮视觉区分。

## 6. 验收要点

1. 风险提示在登录后所有页面常驻，且文字与需求完全一致。
2. 扫描前必须至少选择一个根目录；排除目录必须在根目录内。
3. 结果中保留项不可勾选删除；需人工组 v1 禁止删除，需在 DSM 中人工处理。
4. 删除必须经过“清单确认 + 最终确认”两个弹窗；永久删除必须输入“永久删除”。
5. 删除请求失败/计划过期时不得静默重试删除。
6. CSV 带 BOM，Excel 打开中文不乱码。
7. 窄屏下仍可完成扫描、查看结果、两次确认。
8. 字幕页目录选择与扫描范围使用同一个选择器；选择后自动枚举，未选择视频时提交按钮禁用。
9. 字幕任务写回结果（路径/跳过/警告）在任务中心列表、详情与单视频弹窗三处展示一致；写回失败不隐藏下载入口。
10. 批次进行中切换页面后返回，进度继续刷新；批次结束有一次性提醒。
11. 批次组执行中时，任务明细/任务中心无需翻页即可看到“执行中”任务（当前执行行 + 置顶区块 + 状态筛选计数）；没有执行中任务时显示排队/等待调度。
12. 补翻译：仅 ASR 的已完成任务在组卡片/明细行/任务中心都有入口；确认后才提交；成功后显示“已创建 N 个翻译任务”并切换到新批次组；已有译文/源缺失/重复任务在汇总中说明；翻译未启用或缺 LLM Key 时入口禁用并显示原因。
13. 语言与输出：识别语言/目标语言下拉覆盖常见 19 种语言码，API 设置的其它合法语言码在设置页保存后仍保留；设置页「译文输出组合」可只写译文或只写双语，任务目录始终保留 original.srt，已写出的旧文件不被删除。
14. 字幕步骤时间线（v0038）：任务详情有「步骤耗时」表（排队/媒体探测/音频提取+识别/翻译/写盘），运行中步骤显示进行中；可展开 ASR 分片/翻译批次明细；旧任务提示未记录。
15. 操作日志删除（v0038）：审计事件可勾选删除，或按“保留最近 N 天”清理审计与日志文件；删除需二次确认，删除动作本身写入审计。
16. 菜单（v0038）：顶部为 扫描 / 字幕 / 任务中心 + 右上角设置；操作日志在任务中心标签页；存储诊断在设置页；旧 `#/logs` 书签可正常跳转。

## 7. 内容相似模式（v1.1 新增）

### 7.1 扫描页模式切换

┌─ 扫描模式 ─────────────────────────────────────────────────────────┐
│  (•) 精准哈希（默认）      ( ) 内容相似（哈希 + 相似）             │
│  精准模式：只显示字节完全一致的文件，最高置信度。                   │
└────────────────────────────────────────────────────────────────────┘
（选择“内容相似”后展开）
┌─ 相似度选项 ───────────────────────────────────────────────────────┐
│ 相似阈值  [=====●==========] 85%   （0–100，越高越严格）          │
│ 允许类型  ☑ txt ☑ md ☑ pdf ☑ docx ☑ png ☑ jpg …  [全选/清空]     │
│ 相似并发  [2 ▾]   ☑ 启用特征缓存   单文件上限 [32] MB            │
│ ▸ 高级：允许未知二进制相似计算（默认关；压缩包/媒体/可执行仍跳过）  │
│ 说明：压缩包、音视频、可执行文件、超大文件只做哈希精准匹配。       │
└────────────────────────────────────────────────────────────────────┘

- 精准模式完全保留原有界面；相似选项默认折叠/隐藏。
- 阈值越高越严格；默认 85。类型关闭即不做相似计算，但仍参与精准哈希。
- 相似阶段可暂停/继续/停止；进度显示“内容相似度分析”、缓存命中、跳过原因。

### 7.2 结果页分区

┌─ 扫描报告 · 内容相似模式 ──────────────────────────────────────────┐
│ [精准组 12] [相似组 8] [精准可释放 3.2GB] [相似潜在 1.1GB]        │
├─ 哈希一致（精准重复）─────────────────────────────────────────────┤
│  组 #1 ...（原有精准组 UI：默认勾选、全选副本、删除）              │
├─ 内容相似 ────────────────────────────────────────────────────────┤
│ ⚠ 内容相似度为 AI/特征比对结果，存在误匹配概率，相似组必须人工复核， │
│   禁止一键批量删除相似文件。                                       │
│                                                                   │
│ ▾ 相似组 #S1  89% · 3 个文件 · 潜在 240MB   [人工复核 ☐]         │
│   ★ 保留（最晚创建） /photo/a.pdf  ... 相似度 100%               │
│   ☐ /photo/b.pdf  ... 相似度 91%  (人工复核前禁用)               │
│   ☐ /photo/c.pdf  ... 相似度 87%  [删除本组选中]（默认置灰）      │
└───────────────────────────────────────────────────────────────────┘

- 相似组没有“全选副本”；人工复核勾选后仍只能逐条勾选。
- 组级“删除本组选中”默认置灰；复核 + 至少选中一条后才启用。
- 全局“全选待删除副本”只作用于精准组，绝不选择相似组。
- 相似组保留项仍按创建时间最晚选择；若时间不可靠，整组禁止删除。
- 结果行显示 match_type、相似度、特征方法/低置信提示；精准行显示哈希，相似行可显示内容 SHA256 或“—”。

### 7.3 删除流程

- 若所选包含相似文件，第一步计划展示：
  - 精准文件数/字节、相似文件数/字节；
  - 已人工复核的相似组数；
  - 黄色提示“相似组已人工复核，仍需逐条核对”。
- 提交计划时携带：

  {"file_ids":[...],"recycle":true,"confirm_similar":true,
   "reviewed_similar_group_ids":["s-000001"]}

- 未复核/无 confirm_similar → 后端返回 SIMILAR_REVIEW_REQUIRED，前端提示重新复核，不发删除请求。
- 两次确认与永久删除短语规则不变。

### 7.4 展示文案（固定）

内容相似度为 AI/特征比对结果，存在误匹配概率，相似组必须人工复核，禁止一键批量删除相似文件。

该文案在内容相似模式的结果页常驻，不替代顶部全局数据丢失风险提示。
