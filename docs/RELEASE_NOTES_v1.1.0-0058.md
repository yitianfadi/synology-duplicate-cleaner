# 重复文件清理与字幕 1.1.0-0058

> 发布日期：2026-11-17 · 类型：**行为调整（下载/转换不再需要开启）** · 适用：DSM 7.0+（noarch）

## 一句话

**「下载」和「转换」是内置功能了：去掉设置里的启用开关，装好即可用。** 以前要在「设置 → 下载 / 转换」里勾选启用才会显示按钮，现在这一步没有了。

## 变化

- **设置页**：删掉「启用下载中心（默认关闭）」「启用格式转换（默认关闭）」两个复选框，以及卡片标题旁的「未启用」徽标；两个分组只保留目录、并发、空闲时段等参数。
- **下载页**：不再有「未启用」徽标；提交按钮不再因开关被禁用（仍要求管理员、仍需选目录）。
- **转换页**：不再有「未启用」状态；只有 **FFmpeg 不可用** 时才禁用提交，徽标显示 FFmpeg 版本与并发数。
- **后端**：`/api/downloads*`、`/api/convert*` 不再因设置返回 403（`DOWNLOAD_DISABLED`/`CONVERT_DISABLED` 仅保留给“服务未装配”的异常情况）；`/api/meta.download.enabled` 与 `/api/convert/capabilities.enabled` 恒为 `true`。
- **旧配置兼容**：`download_enabled` / `convert_enabled` 两个设置键仍然接受（旧客户端/旧 `settings.json` 不会 400），但**值不再生效**；默认值改为 `true`。升级后即使旧配置里是 `false`，下载与转换也照常可用。

## 为什么

下载中心和格式转换各自已经是独立页面（v0051 / v0056），再要求先去设置里“开功能”只是历史遗留的门槛：用户点进页面发现按钮全灰，还要跳设置——两步才能做一件事。现在按“内置能力”对待，只保留真正需要的参数（目录、并发、空闲时段、删除源确认）。

## 兼容性

- API 路径、请求/响应结构、错误码、SQLite schema（v10）都不变；唯一的行为变化是“不再 403”。
- 升级：设置、下载/转换任务历史、产物全部保留；无需迁移。
- 安全边界不变：仅管理员；下载仍做 SSRF 防护、拒绝 DRM/直播；转换的「删除源文件」仍需二次确认，产物校验通过后才删源；输出目录必须在共享文件夹内。

## 验证

- 后端 unittest：**826 通过 / 0 失败**（5 个跳过；原「未启用应 403」的 3 个用例改为「开关值被忽略、仍可创建」）。
- 静态检查：**235 PASS / 0 FAIL / 0 UNVERIFIED**（新增 `FE-NOGATE-V0058`：后端无开关闸门、设置页无启用复选框、页面无未启用徽标）。
- e2e：**245 PASS / 0 FAIL / 1 UNVERIFIED**（`DL-00`/`CV-00` 改为验证“`*_enabled=false` 时接口仍 200”）。
- 前端：模块图 35/35、无头冒烟 8/8、Chromium 交互探针通过。

## 安装 / 升级

1. 套件中心 → 手动安装 → 选择 `DuplicateCleaner-1.1.0-0058.spk` → 覆盖安装。
2. 升级后直接打开「下载」「转换」页即可用；如需默认目录/并发/空闲时段，再到「设置 → 下载 / 转换」调整。
