## 2. 关键取舍（"做不到/需改法"的落地方式）

1. **"增量扫描只比对新增/修改文件"不可行 → 哈希缓存 + 增量视图**。只比新增会漏掉"新文件与未变化旧文件重复"这个主场景，也会漏"旧文件修改后变重复"。实际实现为：枚举仍 `stat` 全部文件，`(dev, inode, size, mtime_ns)` 未变则复用哈希、不读内容；结果另给"本次新增的重复"筛选。收益：第二次扫描读取 IO 接近 0，判定语义与全量扫描一致。
2. **"权限一键向导"无法自动配置 → 只读体检 + 精确指引**。套件以非 root 用户运行，DSM 也没有向第三方套件开放的提权接口；内置 root 脚本改 ACL 会把"套件能改系统权限"变成安全风险。实际交付只读检查 + DSM 界面路径 + 可复制的 `synoacltool` 命令文本（只显示不执行）。
3. **相似视频不承诺"不同剪辑版本/花絮" → 分档置信度 + 人工复核**。能稳定处理同源不同分辨率/码率/封装、轻微时间偏移、不同黑边；剪辑、片头片尾、水印台标只能给分档，最终由并排预览人工判断。
4. **硬链接合并不可逆 → 独立操作 + 补偿动作**。合并不是删除的替代项：默认关闭、逐组确认、二次确认；合并后任一路径修改全局生效；提供「恢复为独立副本」（Btrfs `FICLONE` 回退复制）兜底。
5. **编码限制无法消除 → 缩略图兜底**。浏览器不能解码 HEVC/VC-1/DTS 等，缩略图仍可见；不提供在线转码，仅保留可选的"低码率片段转码"开关（默认关，CPU 代价）。
6. **DSM 通知仅登录可见 → 多渠道可选**。`synodsmnotify` 只在用户登录 DSM 时可见；需要可靠触达时用 Webhook/Telegram（要求 NAS 能出网）。

## 3. 明确不做

1. 任何自动删除 / 自动合并 / 扫描完成顺手清理（坚持"扫描 → 报告 → 人工确认 → 二次确认 → 可回收 → 审计"）。
2. 相似/视频相似组免人工复核（门禁保持：图片/文档相似组禁止组级全选）。
3. 套件提权修改 ACL。
4. 跨文件系统硬链接（Linux 不支持，跨卷自动跳过）。
5. 完整 gitignore 语义（`**` 等，只实现常用子集）。
6. 视频实时在线转码播放（只保留可选的低码率片段转码开关）。
7. 用 ctypes 实现 inotify 实时监控（改为轮询）。

## 4. 默认值（已按此实现）

| 项 | 默认 | 理由 |
|---|---|---|
| 跨扫描哈希缓存 | 开 | 纯加速，不改变判定 |
| 硬链接合并 | **关** | 不可逆，需逐组确认 |
| 套件独立回收站 | 关（沿用共享文件夹 `#recycle`） | 保持现有行为与 DSM 回收站一致 |
| 删除白名单 | 开（常见字幕/元数据后缀） | 保护字幕/海报/nfo |
| 计划扫描 | 关 | 避免无人值守自动扫描 |
| 通知 | 关（配置后才发） | 避免误扰 |
| 视频目录监控 | 关（10 分钟轮询） | 大目录枚举成本 |
| 音频签名相似 | 关 | 性能 |
| 音轨选择 | `auto`（首音轨） | 兼容旧任务 |
| 字幕负载阈值 | 0 = 关闭 | 不改变现有行为 |
| `.ignore` / 正则排除 | 开（空配置无影响） | 无副作用 |
| 静音预检 | 关 | 提交成本高 |

## 5. 真机验证清单

NAS 已于 2026-11-10 由 `1.1.0-0042` 覆盖升级到 `1.1.0-0050`；以下项仍需在真机逐项确认：

- [ ] 连续扫描两次，第二次 `hashed_bytes` 接近 0，组数/文件数与首次一致；删除前重校验通过
- [ ] Btrfs 同卷硬链接合并：`stat` nlink 增加、`df` 释放空间、`synoacltool -get` 元数据一致；跨卷（volume1↔volume2）跳过原因正确
- [ ] 套件回收站整组恢复：哈希一致；与原位置同名文件冲突时跳过且不覆盖
- [ ] 4K WMV/MKV 缩略图抽帧耗时与成功率（4 核、高负载下）；HEVC/MKV 提示符合预期
- [ ] 高负载时字幕队列"暂停取任务"、降载后自动恢复；置顶任务下一个执行
- [ ] 多音轨文件按语言/序号选轨后识别内容正确
- [ ] 目录监控：新增视频在间隔内自动入队；套件停止期间不监控
- [ ] 权限体检对未授权共享文件夹给出正确问题与指引
- [ ] `synodsmnotify` 以 `duplicatecleaner` 身份能弹出 DSM 通知；Webhook/Telegram 可达
- [ ] 计划扫描在负载超阈值/已有扫描时跳过，且不补跑

## 6. 与后续版本的关系

- **v0050** 修复的是本批需求交付后暴露的批次组操作问题（取消超时、总览不能删、明细不能批量取消、手动加载、已取消任务混在失败页签），不改变本文件的需求口径。
