# 发布说明 · v1.1.0-0063

> 主题：转换页「已选文件」改为分页显示（选择集仍是全量，只渲染当前页）
> 升级方式：套件中心手动安装覆盖升级；数据目录、包 ID 与 SQLite schema（v11）不变。
> 说明：v0061、v0062 与 v0063 尚未单独发版，本说明覆盖三者增量。

## 1. 已选文件列表分页显示（v0063）

- 以前「列出文件」后会把**所有**候选（最多 2000 个）一次性塞进列表，页面很长、滚动卡顿；
  现在列表**只渲染当前页**（默认 60 条），其余仍在选择集里。
- 列表面板新增：
  - **搜索框**：按文件名或路径筛选（不区分大小写），带「清除筛选」；
  - **分页**：`上一页` / `第 x/y 页` / `下一页`，每页可选 **60 / 120 / 240**；
  - **摘要**：`已选 1280 个文件 · 共 12.3 GB · 显示 1–60 · .mkv 900 · .mp4 380`；
  - 空状态提示区分「还没选文件」与「筛选无结果」。
- 列表区固定提示：**「列表只显示当前页；未显示的文件同样会被提交」**，避免误以为没选上。
- 「全选本次列出」「清空」「逐行取消勾选」语义不变；取消勾选导致页数变少时页码自动回退。
- 提交行为不变：仍按 `cs.selected` **全量**分批提交（每批 ≤200，v0062）。
- 重新「列出文件」或提交成功清空后，自动回到第一页并清掉筛选。

## 2. v0062 增量：批量提交自动分批

- 单请求上限仍为 200 个文件（`CONVERT_BATCH_MAX_ITEMS`），前端自动每 200 一批连续提交，
  显示「正在分批提交…（3/5 批，已提交 600/1000 个）」，整目录（枚举上限 2000）可一次提完。
- 只把真正入队的文件移出「已选」；被拒文件保留并提示原因；某批失败时已完成批次保留、剩余仍可再提交。
- 活动任务上限 `convert_job_limit` 默认 **500 → 2000**，旧默认值一次性迁移（写审计）。

## 3. v0061 增量

- 源文件后缀可多选（视频/音频分组 + 全选/清空/仅视频/仅音频），只枚举勾选的后缀；
  `extensions` 严格校验（未知后缀/空数组 → 400），勾选存 `convert_source_extensions`。
- 同名目标默认 `trash`：覆盖并把旧产物移入套件回收站（可恢复），不再生成 `名称 (2).mp4`；
  源=目标（同目录同格式）仍强制加序号。
- 默认转换成功后删除源文件（`convert_delete_source=true`）、不再弹二次确认；
  失败/取消/超时一律清 `.dcpart`。

## 4. 兼容性

| 项 | 变化 |
|---|---|
| SQLite schema | **v11 不变**，无迁移 |
| 设置 | v0062：`convert_job_limit` 默认 2000（旧默认 500 一次性迁移）；v0061：`convert_delete_source`（true）、`convert_source_extensions`（[]）、`convert_overwrite` 默认 `trash`；`convert_keep_source` / `convert_keep_temp` 为兼容键 |
| API | 无新增；`capabilities` 含 `limits` 与 `source_extensions`（v0061/v0062）；分页纯前端行为，接口不变 |
| 前端 | 已选列表分页 + 搜索 + 后缀多选 + 自动分批提交；列表行数 ≤ 每页条数 |
| 数据安全 | 「覆盖 + 删源」默认组合不可逆，旧产物在套件回收站可恢复；回收站不自动清理 |

## 5. 安装

1. 下载附件 `DuplicateCleaner-1.1.0-0063.spk`；
2. DSM → 套件中心 → 手动安装 → 覆盖升级（数据保留）；
3. 打开「转换」页：选目录 → 勾后缀 → 列出文件，确认列表只显示 60 行且可翻页/搜索；
   选 300 个文件点「开始转换」应显示分 2 批提交。

## 6. 校验

- 文件大小 / SHA256 / package.tgz MD5：见 Release 附件与 `dist/*.sha256`。
