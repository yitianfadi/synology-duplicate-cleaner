# 发布说明 1.1.0-0051（下载中心）

- 版本：`1.1.0-0051`
- 日期：2026-11-15
- 基线：`1.1.0-0050`
- 重点：新增「下载」页 —— 直链 / HLS(m3u8) 批量下载并合并为 MP4，可直接保存播放网页里的视频流。

## 1. 这次新增了什么

### 1.1 下载中心（新页面）

- 主导航新增「下载」（`#/download`）：粘贴地址（每行一个）即可批量入队，也可单个下载。
- 支持两类输入：
  - **直链**：任意 `http(s)` 文件（mp4/mkv/zip…），支持 HTTP Range 断点续传；
  - **HLS（m3u8）**：主/媒体播放列表、TS、fMP4（`EXT-X-MAP`）、`EXT-X-BYTERANGE`、多码率自动选档、独立音轨（`EXT-X-MEDIA`）合并。
- **AES-128 加密流**：分片与密钥先落地，重写成只引用本地文件的播放列表，再交给内置 FFmpeg 用原生 AES 解密并无损封装为 MP4（不在标准库里造 AES 轮子，NAS 上也不会被 CPU 拖死）。
- 合并为 MP4：`-c copy` 无损封装；失败自动回退一次「视频复制 + 音频 AAC」；合并后用 FFprobe 校验时长，超容差只标记警告。
- 队列与并发：任务级并发 1–4（默认 2）、单任务分片并发 1–16（默认 4）、全局限速（按任务均分）、剩余空间闸门；超出并发自动排队（FIFO），可暂停 / 继续 / 取消 / 重试 / 删除，批量组可整组操作。
- 断点续传：分片级（已存在即跳过）与直链 `Range` 续传；套件重启后「运行中」任务重新排队继续。
- 输出：默认写共享目录（目录用选择器挑，不写死）；可选按站点 / 日期 / 站点+日期 / 自定义模板（`{site}/{date}`…）分子目录；同名文件默认不覆盖、自动加序号。
- 防盗链/登录态：支持自定义 User-Agent、Referer、Cookie、代理（Cookie 为密钥键，只写不读）。
- 安全默认：拒绝内网/回环地址（SSRF）、拒绝带账号密码的 URL、输出目录必须落在共享文件夹内；需要下载局域网源时在设置里显式放开。
- 完成联动（可选）：自动入队扫描该目录（同目录 10 分钟去抖）/ 自动提交字幕任务。

### 1.2 明确不做

DRM（Widevine/FairPlay/PlayReady）与 SAMPLE-AES 不做任何绕过；不支持直播/滚动播放列表（无 `EXT-X-ENDLIST`）；不内置浏览器，不做 JS 渲染页的自动嗅探（可手动抓出 m3u8 地址粘贴，后续版本再补网页解析）；不做转码，只做无损封装。

## 3. 安装步骤

1. 套件中心 → 手动安装 → 选择 `dist/DuplicateCleaner-1.1.0-0051.spk`（覆盖安装，保留数据）。
2. 打开 `http://<NAS>:8787` → 右上角「设置」→「下载」→ 勾选「启用下载中心」并选择默认下载目录（必须在共享文件夹内）。
3. 若下载目录不可写，请到 DSM「控制面板 → 共享文件夹 → 编辑 → 权限 → 系统内部用户」给 `duplicatecleaner` 授予读写权限。
4. 打开「下载」页，粘贴地址 →「开始下载」。

## 6. 回退

- 直接安装上一版 `DuplicateCleaner-1.1.0-0050.spk` 即可回退；schema v9 对旧版是「更高版本」，旧版按兼容模式打开（只读风险自担，建议回退前先 `POST /api/storage/backup` 备份数据库）。
- 下载产物与临时目录不会被回退删除；如需清理，删除共享目录下的 `.dc-download-*` 目录即可。
