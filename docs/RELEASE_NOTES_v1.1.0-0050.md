# 1.1.0-0050 · 重复扫描增强 + 字幕 ASR 优化 + 任务中心/权限/日志

本版把 **v0043 → v0050** 共 8 个版本一起发布（上一正式版为 v1.1.0-0042）。
核心是 v2 需求文档的全部落地：重复扫描的增量缓存/保留规则/预览/合并/回收站、计划扫描与通知、
相似视频增强，字幕 ASR 的失败重试/资源管控/音轨/目录监控，以及任务中心检索、权限体检、日志增强
和批次取消/删除。

## 重复文件扫描

### 增量扫描、保留规则、排除规则（v0043）

- 跨扫描 **SHA-256 哈希缓存**：内容未变不重算；新增/修改文件才重新哈希，海量目录第二次扫描显著加速。
- **保留规则链**：创建时间最早/最晚、修改时间、访问时间、体积最大/最小、路径优先级、文件名优先级、
  优先带字幕/内嵌音轨版本；规则可组合并给出 `keep_reason`。
- **预扫描快速过滤**：大小分组 → 大文件头尾部分哈希初筛 → 全量哈希确认。
- **排除规则增强**：文件名正则、glob、忽略符号链接、读取 `.ignore` 文件，并兼容影视库海报/nfo 等附属文件。

### 预览与删除保护（v0044）

- 结果页视频**缩略图条 + 媒体信息**，点击缩略图跳转播放；同组两文件**并排同步对比**；Range 流式播放。
- **删除白名单**：按目录、后缀、正则保护外挂字幕/nfo/海报等附属文件，三层防线（扫描标记、预检、删除复核）。

### 硬链接合并与套件回收站（v0045）

- Btrfs 友好：默认关闭，逐组确认后将重复副本替换为硬链接，保留可读文件与创建时间语义。
- **套件独立回收站**（`#duplicate-cleaner-trash`）+ manifest：删除文件可整组恢复/清理，不依赖群晖回收站。
- 合并可“恢复为独立副本”（Btrfs FICLONE），避免不可逆误操作。

### 计划扫描与通知（v0046）

- 计划扫描：每天/每周/固定间隔，可限定低负载时段；负载超阈值或扫描进行中自动跳过并通知。
- 通知渠道：**DSM 系统通知 / Webhook / Telegram**；事件覆盖扫描完成/失败、释放空间达到阈值、
  字幕批次结束、大量任务失败；每个渠道可单独测试。

### 相似视频识别增强（v0047）

- 帧指纹 v2：中心裁剪 + 黑边检测内容裁剪，降低不同压制版本边缘差异影响。
- 时间轴偏移对齐、可选音频包络签名、置信度分档（高/中/低）与匹配方式展示；
  仍不承诺识别“不同剪辑版本”，结果需人工复核。

## 字幕 ASR

### 失败分类、自动重试、资源管控、音轨、目录监控（v0048）

- 失败 9 分类（音频提取/无语音/超时/码流/权限/网络/云端/内部/未知），可恢复错误自动重试；
  无语音任务标记跳过，不占队列。
- 失败清单展示/CSV 导出/批量重识别；资源负载阈值超限自动暂停取新任务；队列优先级/手动置顶/
  目录优先级；ETA 按最近实际耗时校准。
- **音轨选择**：按序号或语言标签提取目标音轨识别，避免误识别配音。
- **视频目录监控**：监控目录新增视频自动加入字幕队列并沿用翻译开关。

### 任务检索、权限体检、日志增强（v0049）

- 任务检索：按状态/路径/目录/后缀/失败分类筛选；批量取消/重试/置顶。
- 权限与路径体检：一键**只读检测**配置目录与共享文件夹可读/可写，汇总扫描/字幕权限异常并给出
  DSM 操作指引；**不自动改 ACL**（非 root 限制）。
- 日志：按任务 ID/关键字检索，可读文本导出。

### 批次取消/删除、任务明细增强（v0050）

- 大批次组“取消剩余”**异步化**：立即返回并显示进度，不再 20s 超时；不会误启动新任务。
- 任务明细支持**取消剩余/取消当前筛选**；批次总览支持**删除**（进行中可强制取消并删除，
  等任务停止后清理）。
- 任务明细**下滑自动加载**；**已取消任务独立页签**；“取消中”状态可见。

## 兼容性

- **SQLite schema 由 v7 自动迁移到 v8**（新增增量哈希缓存等），无需手动操作；升级前建议备份
  `/volume1/@appdata/DuplicateCleaner`。
- 包 ID、安装 URL、数据目录不变，可直接覆盖升级；扫描历史/字幕任务/日志保留。
- 新功能默认值偏安全：硬链接合并默认关闭、相似视频组默认不勾选、权限体检只检测不改权限。
- 页面与接口均有版本号；旧任务 JSON/旧批次组记录可读。

## 安装

1. 下载附件 `DuplicateCleaner-1.1.0-0050.spk`；
2. DSM → 套件中心 → 右上角「手动安装」→ 选择该文件（覆盖升级，数据保留）；
3. 安装后自动启动；首次启动会做 schema v7→v8 迁移，数据量大时可能需 10–60 秒。
