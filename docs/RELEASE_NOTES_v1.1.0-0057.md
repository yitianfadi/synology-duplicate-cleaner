# 重复文件清理与字幕 1.1.0-0057

> 发布日期：2026-11-17 · 类型：**界面信息架构调整（无后端接口变更）** · 适用：DSM 7.0+（noarch）

## 一句话

独立「任务中心」页面退役：扫描历史、删除与回收站、字幕任务、操作日志按归属拆入 **扫描 / 字幕 / 设置** 页的内嵌标签，顶部导航精简为「扫描 / 字幕 / 下载 / 转换」+ 右上角设置。

## 为什么要改

- 旧「任务中心」把 5 类互不相干的东西塞进一页（扫描历史 / 字幕任务 / 删除任务 / 回收站与合并 / 操作日志），默认还停在「扫描历史」——为了看一个字幕任务要先点导航再点标签，并白拉一次历史。
- 字幕页早有「批次总览」、下载/转换页各有队列，只有字幕任务明细还留在任务中心 → 同一批数据两套视图、两套轮询，长期必然漂移。
- 后端接口本来就是按模块拆的（`/api/history`、`/api/subtitles/*`、`/api/deletions`、`/api/trash|merges`、`/api/logs`），所以这次只动前端结构。

## 变化

| 原「任务中心」标签 | 现在的位置 | 深链 |
|---|---|---|
| 扫描历史 | 扫描 → 历史 | `#/scan?tab=history` |
| 删除任务 + 回收站与合并 | 扫描 → 删除与回收站 | `#/scan?tab=deletion` |
| 字幕任务 + 失败任务 | 字幕 → 任务（与批次总览同页） | `#/subtitles?tab=jobs` |
| 操作日志 | 设置 → 操作日志 | `#/settings?tab=logs` |

- **导航**：`扫描 / 字幕 / 下载 / 转换` + 右上角「设置」（去掉了「任务中心」）。
- **标签引擎**：统一 `setTab(view, tab)`，`aria-selected` / roving tabindex / 面板 `hidden` 与懒加载；键盘 ←→ / Home / End 可切换。
- **深链**：`#/<view>?tab=<tab>` 双向同步（默认标签不带 `?tab=`），刷新/前进后退可恢复。
- **轮询闸门**：字幕任务只在「字幕 → 任务」标签下轮询；离开标签或切换视图立即停止，不再后台空转。
- **文案**：字幕页「在任务中心查看」→「查看任务列表」；「去任务中心查看」→「去任务列表查看」；删除向导/结果页的“整组恢复”指向「扫描 → 删除与回收站」；DSM/Telegram 通知里的指向同步更新。
- **旧书签**：按需求**不**做重定向，`#/history`、`#/logs` 会落到扫描页默认标签。

## 内部重构：app.js 拆分（同一版本内完成）

IA 调整后，把原本堆在 `app.js` 里的面板代码按归属拆成模块（行为不变、后端不变）：

| 新模块 | 内容 |
|---|---|
| `js/labels.js` | 扫描模式判定、保留/删除原因标签等共享小函数 |
| `js/scan-history.js` | 扫描历史列表（渲染 / 继续扫描 / 打开旧结果） |
| `js/deletion-jobs.js` | 删除任务表 |
| `js/trash-page.js` | 套件回收站 + 硬链接合并记录 |
| `js/logs-page.js` | 审计事件 / 日志文件 / 日志检索 |
| `js/subtitle-shared.js` | 字幕状态标签、输出渲染、语言下拉等结果页与任务面板共用的小函数 |
| `js/subtitle-jobs.js` | 字幕任务列表、失败面板、详情弹窗、SRT 预览、批量操作、轮询 |

- `app.js` 从 **11,694 行降到 9,036 行**（−22.7%），`js/` 下共 19 个模块。
- 模块不反向 `import app.js`；跨模块动作走 `state.js` 钩子（`openScan`、`openSubtitleJobs`）。
- 每个模块自带 `initXxx()` 绑定自己的按钮；顺带修复「回收站 → 刷新」按钮此前从未绑定监听器的问题。
- 拆分不改变任何接口、DOM id 或用户操作路径；QA 基线与拆分前一致（见下）。

## 兼容性

- API、错误码、设置键、SQLite schema（v10）**全部不变**；升级后数据与任务历史原样保留。
- 原地升级：设置、扫描历史、字幕任务、删除/回收站/合并记录、日志均无需迁移。
- 若习惯旧入口：记 4 条深链即可（上表右列），收藏夹直接存 `?tab=` 版本。

## 安装 / 升级

1. 套件中心 → 手动安装 → 选择 `DuplicateCleaner-1.1.0-0057.spk` → 覆盖安装。
2. 升级会短暂重启套件；正在运行的字幕/下载/转换任务会回到队列（与以往版本一致）。
3. 升级后打开 `http://<NAS>:8787/`，直接点「扫描 → 历史」「字幕 → 任务」验证旧数据仍在。
