# 重复文件清理与影音工具 1.1.0-0059

> 发布日期：2026-11-17 · 类型：**新功能（音视频合成）+ 更名** · 适用：DSM 7.0+（noarch）

## 一句话

新增「合成」页：**把视频片段与音频片段按选择顺序拼成一条最终音视频**；同时把软件显示名从「重复文件清理与字幕」改为 **「重复文件清理与影音工具」/ Duplicate Cleaner & Media Toolkit**。

## 新功能：音视频合成（导航第 5 项）

- **顺序即结果**：两个有序列表（视频片段 / 音频片段），每行一个路径；视频按顺序拼成画面、音频按顺序拼成声音，再混流为一个文件。
- **三种典型用法**：
  - 1 个视频 + 1 个音频 → 混流成带声音的视频；
  - 多个视频片段 → 按顺序拼成一条长视频（音频可留空 = 无声视频）；
  - 多个音频片段 → 按顺序拼成一条音轨，再与画面合成。
- **自动选路**：素材编码/分辨率/帧率/音频参数一致时直接 `-c copy`（秒级、无损）；不一致时自动统一转码（scale/pad/fps + 48kHz 立体声 AAC），也可手动选「仅直拷」或「统一转码」。
- **时长规则**：以拼接后的视频总时长为准——音频不足**静音补齐**，超出**截断**。
- **容器**：MP4（通用）或 MKV（兼容任意编码）。
- **目录加入**：选目录后可枚举素材，一键「加入视频 / 加入音频」，顺序即点击顺序，可手动调整行序。
- **安全**：源文件必须在共享文件夹内、拒绝符号链接；产物先写 `.dcpart`，校验（有视频轨、有音频轨、时长匹配）后原子改名；**绝不覆盖源文件**；「合成成功后删除源文件」默认关闭，勾选后仍需二次确认，且只在校验通过后删除。
- **队列**：并发 1–2、进度/阶段、取消/重试/删除（可选删产物）、重启后运行中任务回到队列；无启用开关，装好即可用。
- **设置**：「设置 → 合成」只放默认输出位置、容器、合成方式、质量、分辨率上限、名模板、并发、保留源文件等参数。

## 安装 / 升级

1. 套件中心 → 手动安装 → 选择 `DuplicateCleaner-1.1.0-0059.spk` → 覆盖安装（显示名会更新，数据不变）。
2. 打开「合成」页：选目录枚举素材或直接粘贴路径 → 按顺序加入视频/音频 → 开始合成。
3. 需要默认输出目录/容器/并发时到「设置 → 合成」调整。
