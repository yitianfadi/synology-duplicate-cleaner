# 重复文件清理与字幕 1.1.0-0056

发布日期：2026-11-17 · 类型：功能版本（新增格式转换）

## 一、这个版本做了什么

新增独立的「转换」页：把视频或音频换成另一种格式，支持**只换封装**（秒级、无损）与**重新编码**，也可以从视频里提取音频。

- **16 个预设**：MP4（H.264/H.265）、MKV（H.264 / 仅换封装）、MP4 仅换封装、WEBM（VP9+Opus）、MOV、TS、AVI；音频 MP3 / M4A / FLAC / WAV / OGG / OPUS / 原音轨提取。
- **换容器与重编码分开标注**：copy 预设只重写容器、秒级完成；重编码预设按质量三档映射 CRF，可选编码速度、分辨率上限、强制立体声。
- **队列与进度**：并发 1–2（默认 1）、实时进度 / 编码速度 / fps / 剩余时间，取消 / 重试 / 删除任务或产物，批量取消 / 重试失败 / 清理已结束，CSV 导出；进程重启后运行中的任务回到队列。
- **安全默认**：默认输出到源文件同目录并自动改名（`名称 (2).ext`），**绝不覆盖原文件**。「转换成功后删除源文件」必须每次勾选并二次确认，且只在产物校验通过后执行，记审计。
- **空闲时段**：可设置只在夜间执行，窗口外任务排队等待，避免与字幕/下载抢 CPU 与磁盘 IO。
- **批量选择**：目录递归枚举（按音视频后缀过滤，跳过符号链接/隐藏/系统目录）或手动粘贴路径，提交前可核对已选列表与总体积。
- **能力探测**：运行时读取 `ffmpeg -encoders`，缺编码器的预设在页面上置灰并说明原因。

## 二、顺带修复的一个真实缺陷

下载中心的 HLS/DASH 合并与封装把产物写成 `*.mp4.dcpart`，FFmpeg 会按扩展名推断容器并对 `.dcpart` 报
`Unable to choose an output format` / `Error opening output files`——也就是说**合并/封装这一步此前必然失败**
（e2e 用的是假字节，没有真跑 FFmpeg，所以没暴露）。

v0056 起：转换的所有预设显式 `-f <muxer>`，下载的 `_merge` / `_remux` 补 `-f mp4`，并新增静态检查
`BE-DOWNLOAD-PART-FORMAT` 防止回退。

## 三、兼容性

- 覆盖升级：`1.1.0-0050` 及以上均可直接覆盖安装；设置与任务数据保留。
- **SQLite schema v9 → v10**：只新增 `convert_jobs` 表（幂等迁移），不动历史数据；降级到旧版本会以兼容模式打开（旧版本看不到转换任务，但不会损坏数据）。
- 转换功能默认**关闭**：装好后在「设置 → 转换」勾选「启用格式转换」并保存；默认输出位置是「源文件同目录」，也可以改成固定目录或固定目录 + 子目录。
- 内置 FFmpeg 已包含 libx264 / libx265 / libvpx / libaom / libmp3lame / libopus / libvorbis / libass；自定义 `ffmpeg_path` 时以实际探测结果为准。

## 四、安装

1. 套件中心 → 手动安装 → 选择 `DuplicateCleaner-1.1.0-0056.spk` → 覆盖安装。
2. 打开套件 → 设置 → 转换 → 勾选「启用格式转换」，按需设置默认预设/质量/并发/空闲时段 → 保存。
3. 打开「转换」页：选目录 → 列出文件 → 选预设 → 开始转换。

> 升级会重启套件，正在运行的字幕/下载任务会被中断并按各自规则恢复（字幕回到队列，下载回队列续传）。

## 五、性能提示

- NAS 无独立显卡，**重编码是 CPU 密集操作**：1080p H.264 `veryfast` 在 4 核 ARM 上大约 0.1–0.3 倍速，1 小时片子可能要 3–10 小时。想快就先用「仅换封装」预设（MKV/MP4 copy）。
- 转换与字幕/下载同时跑会抢磁盘 IO：NAS 上建议并发 1 + 开启「仅空闲时段」。
- HDR 源转 H.264 颜色会偏灰（v0056 不做 tonemap）；需要保真请用「MKV 仅换封装」。

## 八、回退

- 直接安装上一版 SPK（如 `1.1.0-0055`）即可回退；schema v10 → v9 不会自动降级，旧版本会以兼容模式打开数据库（`convert_jobs` 表被忽略）。
- 转换产物在文件系统里，回退不会自动删除；如需清理，删除产物与 `<目标>.dcpart` 即可。

## 九、已知限制

- 不做：音频→视频、图片/字幕文件转换、字幕烧录、GPU 硬编、HDR tonemap、DRM、直播。
- 不支持单任务断点续转（FFmpeg 能力所限）：取消后重试是从头开始。
- MP4 仅换封装只接受 H.264/HEVC/AV1 + AAC/MP3/AC3/EAC3/ALAC；其他编码请用「MKV 仅换封装」。
