## 1.1.0-0068（2026-11-27）

**下载任务可清空已完成 / 失败 / 已取消**（当前最新）

- 下载页「下载任务」工具栏新增**清空已完成**与**清空失败/取消**两个按钮：二次确认后删除对应任务记录，**不删除已下载的文件**；对应状态为 0 时按钮置灰。
- 接口 `POST /api/downloads/bulk` 支持 `{"action":"clear_finished","scope":"done|failed|cancelled|failed_cancelled|finished"}`（省略 scope = 全部已结束），单次最多 500 条；清空失败/取消前仍可用「重试失败」或逐条删除。
- 无数据库迁移（schema v11）。

## 1.1.0-0067（2026-11-22）

**下载失败指数退避自动重试**（当前 Latest）

- 退避：`min(cap, base×factor^(n-1))` + 0–20% 正向抖动；默认 60s → 180s → 540s → 1620s → 1800s（封顶），最多 5 次（可配 0–10 次、10–600s 首次等待、2–5 倍、60–7200s 封顶）。
- 只重试临时故障：5xx、408、425、429、断网/超时、分片失败、内部竞态；4xx（400/401/403/404…）与 URL/播放列表/输出/空间/直播/DRM/FFmpeg 错误立即失败。
- 支持 `Retry-After`（429/503），取二者较大值且仍受封顶/次数限制；重试走断点续传。
- 界面：设置 → 下载新增 5 个控件 + 实时节奏预览；任务行显示「等待重试（第 N/M 次，约 X 后）」与上次失败原因；手动「重试」重置计数。
- 同时包含 **v0066**（未单独发版）：字幕并发 1–4 与已完成保留上限 20–1000 回到「字幕 → 任务」标签。
- 无数据库迁移（schema v11）。

## 1.1.0-0066（2026-11-20）

- 修复 v0060 设置页瘦身导致的「字幕并发无处可设」：并发任务数（1–4）与保留上限（20–1000）回到「字幕 → 任务」标签，改完立即生效，保留上限不再要求重启。
- 未单独发版，随 1.1.0-0067 发布。

## 1.1.0-0065（2026-11-19）

- 转换支持 Intel 核显硬件编解码：内置 FFmpeg 换 8.1（VAAPI）、随包 libva + iHD/i965、`privilege` 加入 videodriver、3 个硬件预设（CQP）、失败自动回退 CPU。
- 实测：H.264 硬编约 3.5×、HEVC 硬解+H.264 硬编全 GPU 约 9×。

## 1.1.0-0064（2026-11-19）

- 修复网页解析：站点对 `identity` 也回压缩正文却不带 `Content-Encoding`，导致解析不到地址；改为协商 gzip/deflate 并按头/魔数解压。
- 下载按解析标题命名：`titles: {url: title}`，`{title}` 用清洗后的片名（不再一律 `index.mp4`）。
